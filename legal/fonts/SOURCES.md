# Bundled fonts

Unmodified files from google/fonts commit `5e35378e6bda803962ee6fd257e444a7d459660d`. SHA-256 hashes and source URLs are recorded in `Paintroid/src/main/assets/fonts/inventory.json`. Original copyright notices and full OFL texts are retained here and in the in-app Font licences page.

Inventory `licence_file` paths are relative to `Paintroid/src/main/assets`, as
opened by Android's asset manager. These ten original fonts point to the existing
`legal/FONT_NOTICES.txt` aggregate, which contains each corresponding source notice
in full. The dedicated files in this directory remain the source records; they
are not separate APK assets. Fonts with dedicated packaged notices retain those
asset paths. Pointer corrections do not change the licence texts or font files.
