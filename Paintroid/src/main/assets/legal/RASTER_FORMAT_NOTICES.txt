BMP, DIB AND GIF FORMAT NOTICES

AN Paint BMP, DIB and GIF encoders:
Copyright (C) 2026 AN Paint contributors. GNU AGPL version 3 or any later version.
These are original application implementations; no third-party encoder code is
copied or linked for these formats. Android supplies their import decoder.

BMP and DIB export write uncompressed 24-bit RGB with row padding. DIB uses
a packed Windows BITMAPINFOHEADER without the BMP file header. Original DIB
validation/wrapping code connects supported packed DIB imports to Android's
BMP decoder.
GIF export writes a single opaque image with an adaptive palette of up to 256
colours and optional error-diffusion dithering. It does not export animation.
