# Independent TIFF fixtures

These synthetic images are generated by `tools/generate_tiff_fixtures.py` under
AGPL-3.0-or-later. They contain no third-party photographs or downloaded profiles.
Run the generator with Python, Pillow (12.3.0 used here), and host LittleCMS and
libtiff installed. The exact linked versions are recorded in `expected.json`.
Base64 keeps binary test data reviewable and consistent with the colour fixtures.

The generator does not call AN Paint's TIFF encoder or decoder. Pillow/libtiff
write LZW (including horizontal predictor), PackBits, CCITT Group 3/4 and JPEG.
A separate minimal serializer writes explicit classic/BigTIFF little/big endian
containers, strips, 16×16 tiles with partial edges, separate colour planes,
packed grayscale/palette samples, RGB/gray 16-bit data, alpha and orientations.
Pillow independently reads each supported fixture; host libtiff scanlines validate
big-endian BigTIFF because Pillow 12.3's EXIF parser rejects that valid variant.

Expected lossless pixels come directly from the synthetic source samples, not
from AN Paint or a round trip. Orientation expectations use the TIFF coordinate
mapping. The JPEG reference is independently decoded by host Pillow/libtiff,
with a three-level per-channel tolerance for different JPEG implementations.
Plain 16-bit samples allow one level for rounding. Alpha allows two levels for
the unavoidable unassociated/premultiplied 8-bit representation conversion.

LittleCMS creates deterministic linear RGB and linear gray ICC profiles using
D65/sRGB primaries. The reference applies the IEC sRGB transfer function to the
original 16-bit samples, including values below the first 8-bit quantization step;
this catches truncation before colour conversion. No host ICC transform is used
to calculate those expected pixels. The decoder must also leave alpha intact.

`multipage` has a patterned 19×13 first page and an unrelated red 7×3 second page.
Three independent classic/BigTIFF files exercise selection of a rotated second
page and a green final page, with different page dimensions and cropped imports.
Twelve negative fixtures cover invalid signature, out-of-file strip addresses,
truncated pixel data, and deliberately unsupported CMYK, Lab and floating-point
samples, plus a TIFF TransferFunction calibration without ICC, invalid ICC data,
and a grayscale ICC profile incorrectly attached to RGB samples. These colour
metadata errors must fail explicitly instead of silently interpreting the samples
as sRGB. Page-chain negatives add a cycle, an out-of-file next directory, and
4097 otherwise valid pages exceeding the explicit 4096-page limit.
The generator produces 56 fixtures and confirms readability of the 44 supported fixtures; the
Android tests exercise actual packaged native code, memory rejection, recovery,
destination preservation, shared import routing, crop/resize and both exports.
