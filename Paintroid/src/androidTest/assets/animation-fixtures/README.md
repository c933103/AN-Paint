# Animation import fixtures

Original 1×1 fixtures for AN Paint, generated by the fixture builders in
`tools/test_animation_metadata.py` (AGPL-3.0-or-later). GIF uses explicit GIF89a
LZW codes and PNG/APNG uses Python zlib. WebP muxes original red/blue lossless
pixel payloads generated with Pillow/libwebp; the complete self-contained
payloads are in the host test, with no Pillow dependency required to rerun it.

Each file has three animation frames. GIF starts black, then white, then black.
APNG and WebP animate red, blue, red. `three-frame-poster.png` additionally has a
green default image that is outside its three-frame animation. The platform's
static PNG import must use that green default image, so the warning describes
it accurately. Independent Pillow decoding checked all frame counts/colours.
