Ajoutez jusqu’à 20 images avec le sélecteur de fichiers d’Android. Le bac inférieur affiche les miniatures, les noms de fichiers, les dimensions des images après recadrage et après tout ajustement avec Même largeur ou Même hauteur et les dates de modification lorsqu’elles sont fournies par le fournisseur de fichiers. Triez par nom de fichier ou date de modification ; le tri ne réorganise pas les images placées.

Appuyez sur une miniature pour la sélectionner. Recadrer l’image recadre cette image ; Recadrage par lot applique des marges en pixels ou en pourcentage aux images sélectionnées. Faites glisser les poignées de recadrage ou saisissez les valeurs. Réinitialiser le recadrage restaure les bords d’origine. Le recadrage est non destructif et peut être annulé.

Maintenez une miniature appuyée, ou faites glisser une image déjà placée dans l’espace de travail, puis déposez-la sur un bord surligné. L’aperçu translucide montre le résultat exact de l’alignement. Une fixation à droite aligne les bords supérieurs ; une fixation en bas aligne les bords gauches. Vous pouvez aussi appuyer sur une miniature puis sur une cible +. Lors de l’alignement sur une cible, la première image commence à l’origine. Les images rattachées peuvent se déplacer lorsque leur image parente est recadrée. Les chevauchements sont refusés lors de l’alignement sur une cible.

Sélectionnez une image et utilisez Position exacte pour définir les coordonnées X/Y de son coin supérieur gauche en nombres entiers de pixels, à partir de zéro. Les autres images conservent leur position et les chevauchements sont autorisés.

Même largeur et Même hauteur donnent à toutes les entrées une dimension commune tout en conservant le rapport hauteur/largeur propre à chaque image. Choisissez Pixels, Pourcentage, Plus petite ou Plus grande. Restaurer les tailles d’origine supprime la normalisation et conserve les recadrages.

Retirer du placement renvoie uniquement l’image sélectionnée dans le bac. Les autres images restent placées ; les images rattachées peuvent se déplacer pour combler l’espace libéré. Supprimer efface uniquement cette entrée. Annuler et Rétablir permettent d’annuler ou de rétablir ces modifications. Faites glisser une image placée pour la réorganiser ; faire glisser un espace vide déplace la vue. Pincez pour zoomer. Tout afficher ajuste le zoom pour montrer tout l’assemblage ; les dimensions de sortie ne changent jamais.

Enregistrer PNG enregistre directement l’image assemblée. Modifier dans Paint la transfère dans l’éditeur principal comme remplacement annulable. Si la sortie dépasse la limite mémoire, choisissez une copie de sortie plus petite si cette option est proposée. Si même une sortie minuscule dépasse cette limite, l’application affiche un avertissement de mémoire au lieu d’un sélecteur de taille. Les fichiers source d’origine restent inchangés. L’assemblage actuel est enregistré localement et se rouvre à votre retour.

Ce mode utilise les mêmes crédits Catrobat/AGPL et de ressources que le panneau «Fichier > À propos, licences et remerciements» de l’éditeur principal.
