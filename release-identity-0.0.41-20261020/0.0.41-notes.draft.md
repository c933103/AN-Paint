# AN Paint 0.0.41

Package `paint.anpaint.android`, version code 98.

## Changes since 0.0.40

### Expanded Czech support

- Add 343 Czech resource entries, including Czech crop plural forms, active editor and assembly Help, gallery and Commons guidance, image/PDF/export diagnostics, and Exact position and crop tools. Correct eight existing labels covering smoothing, pixel-edge antialiasing, quality, Use image, Copy credit, the colour wheel, ASCII art and colour dithering. Czech resource presence increases from 373 to 716 of 717 current entries.
- Preserve the independent review's 645 bounded static accepts and all 72 holds. Resource presence is not whole-language approval. The dormant legacy manual remains absent, and the existing no-consumer, layout, native-speaker and accessibility limits remain open.

### Prevent silent sign loss in numeric input

- Preserve a pasted Unicode minus sign (`−`, U+2212) in the shared numeric-input filter. Previously, in locales such as Czech and English, dropping that sign could turn a negative-looking coordinate into an accepted positive value and move an image to the wrong position.
- Existing parsers and allowed ranges are unchanged. Unsupported spellings may still be rejected; they must no longer become positive merely because the input filter removed the sign. This is not support for arbitrary Unicode numeric syntax or a change to keyboard modes.

### Regression coverage

- Add Czech compiled-resource and real-consumer checks for Commons failures, crop plural transitions, Help/provider wording, Exact position, PDF/TIFF validation and cancellation. Shared message-family fixtures retain Swedish and other existing expectations while adding the explicitly reviewed Czech values.
- Cover Unicode-minus preservation across the 171 offered locales and both integer/decimal keyboard modes in host Android tests. Focused real-dialog tests cover both coordinates, unchanged image/project state after invalid input, Cancel/reopen and valid native-digit input. The original failing baseline and unchanged control tests remain preserved.

### Known limits

The Czech original bulky review archive upload remains pending separately; the public integration summary identifies the locally verified original receipt and supplements but does not contain their full bodies. Seventy-two Czech review/context holds remain, including source-only or proposed-source entries and the existing `ui_fit` layout concern. There is no whole-locale, native-speaker, installed Czech layout, physical-device or TalkBack certification.

The existing three Swedish holds, nine Afrikaans holds and broader language, glyph/shaping, layout/input and accessibility work remain open. Host Robolectric SDK21/25/30/35 checks do not establish physical Android 5/7 device compatibility. Existing SDK-specific emulator exclusions remain explicit. Published 0.0.40 and its assets are unchanged.
