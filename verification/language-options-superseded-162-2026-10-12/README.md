# Superseded 162-option candidate evidence

This is historical evidence for the unpublished candidate that used broad `nah`
and `qu` placeholders. After the maintainer clarified “the main ones”, that
candidate was superseded. It was not committed to the working branch or opened
as a pull request. These 575-test results and independent review do not accept
or verify the replacement 167-option candidate.

The active implementation instead selects the reviewed concrete varieties
`nch`, `nhe`, `nhw`, `quz`, `quy`, `quh` and `qug`. Fresh source review and test
results for that implementation are kept separately. Prior snapshot hashes and
counts below are intentionally unchanged historical records, not current status.
