## Meaning and language evidence

The SVG note records conversion to PNG at the original dimensions, with the
three unchanged technical settings. The raster note records white-backing
compositing according to source alpha. It must not claim that raster input was
SVG, that transparency was simply dropped, or that a user opacity setting was
changed.

Authoritative technical references consulted:

- [GIMP compositing implementation documentation](https://developer.gimp.org/core/algorithm/compositing/)
  explains combining per-pixel color and alpha against a background. This
  supports the operation's meaning, not fluency in any translation.
- GIMP's [French](https://docs.gimp.org/3.0/fr/glossary.html),
  [German](https://docs.gimp.org/3.0/de/glossary.html) and
  [Japanese](https://docs.gimp.org/3.0/ja/glossary.html) glossaries establish the
  alpha/transparency relationship and relevant terminology. The Japanese
  glossary's intermediate visibility sentence is not used as an algorithmic
  definition; its endpoint descriptions and the implementation reference are
  the check on meaning.
- Existing `ui_original_size34` and anti-aliasing captions are terminology
  references, not runtime fragments or proof that new grammar is correct.
