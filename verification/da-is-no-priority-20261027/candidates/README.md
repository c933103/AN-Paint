# Danish, Icelandic and Norwegian P0/P1 candidates

Source: [`651ab24b2c4dfd26d432daf0d8771fdb179ff013`](https://github.com/c933103/AN-Paint/tree/651ab24b2c4dfd26d432daf0d8771fdb179ff013), tree `d06833e6d8cd1ec700fd03f61858433290808ab7`.

This is one three-language work unit: Danish (`da`), Icelandic (`is`), and Norwegian (both offered `no` and `nn`; `nb` is not offered). Each catalogue accounts for all 92 P0 and 249 P1 identities. Complete English/current/candidate values, attributes, source consumers and prior receipt bindings are included. Consumer text remains inspectable in the pinned source; file hashes bind the source inventory.

**Candidate stage; the Icelandic P0 unit has independent exact-value review, while full P1/inherited-value review is in progress. No proposed resource value has been integrated.** Proposed counts may change during review. Exact prior Danish/Norwegian/Nynorsk P0 receipts are carried, not counted as new review. Existing unknown-confidence values also receive review dispositions before integration. The six explicit absent holds per catalogue remain absent; simple dormant labels have only proposed wording-level scope, not current UI acceptance.

Finnish, Estonian and Latvian are not new work in this unit: their full earlier reviews and applied corrections are preserved. This unit makes no native-speaker, whole-language, installed-layout, or runtime certification claim. Tests and exact-head hosted verification will be reported separately after review and integration.

Icelandic dithering terminology was checked against the [official GIMP Icelandic translation archive](https://mail.gnome.org/archives/commits-list/2020-December/msg03993.html); this is terminology support, not native review.

No release, frozen PR, Help, callback or archive work is included.
