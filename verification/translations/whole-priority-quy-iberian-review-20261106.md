## Language evidence and limits

Quechua compositions use three-vowel Ayacucho/Chanka evidence, not an unexamined Cusco substitution:

- [Soto Ruiz, Ayacucho-Chanka functional dictionary](https://studylib.net/doc/8717719/runasimi-kastillanu-inlis-llamkaymanaq-qullqa): root meanings, examples and suffix grammar. Independently checked pull/stretch, reach/suffice and want/need senses.
- [Quintero Bendezú vocabulary, Huanta/Huancavelica teaching context](https://pdfcoffee.com/diccionario-quechua-chanka-genaro-5-pdf-free.html): selected ordinary, educational and computing senses. Independently checked memory/free memory, combining into a whole, oblique/thick writing and rectangle. Other-variety/archaic entries and poor technical equivalents were not accepted automatically.
- [MINEDU Ayakuchu Chanka dictionary record](https://repositorio.minedu.gob.pe/handle/20.500.12799/10380) and [inspected reproduction](https://pdfcoffee.com/diccionario-quechua-chanka-pdf-3-pdf-free.html): variety/orthography and drawing/writing vocabulary. The official record's human-verification obstacle was not bypassed. Reproductions are identified as such, not described as official-host retrievals.

These sources support words and constructions, not independent native approval of AN Paint sentences. Kipu for file and other software extensions remain contextual conventions; technical identifiers such as RAM, pixel, RGB and vector are openly retained. Functional compositions and narrow controls have idiom/layout qualifications, not fabricated certification or an invented requirement for an exact previously published UI sentence.

**Inherited fallback remains explicit:** `formats22_animation_message` can receive its count from untranslated P2 `formats22_at_least_frames`, yielding English “at least …” inside the translated P0 template. Existing Quechua references to Quality, Lossless and Image credits likewise match actual lower-priority fallback controls. Missing P2/P3 was not filled to conceal this. Direct P0/P1 presence is not a claim that every runtime parameter in those dialogs is localized; this dependency must be reconciled under the existing scope before declaring the release condition satisfied.
