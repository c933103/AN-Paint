## Complete review and concrete findings

The authoring pass assessed all 229 gaps and all 114 existing entries individually. Independent integration review read all target values and assessments against English and consumer meanings, verified all 343 current source records and 114 base values, and reconciled **477 exact production consumer line references**. Important memory, recovery, conversion, animation and action-route branches received direct code review. Source-only entries remain inventory review, not asserted runtime coverage.

Six existing repairs fix Copy/Copy all lexical-tone consistency, restore the Save… ellipsis, remove repeated Saved completion, specify the selected unwritable location and bind protective autosave guidance to the new localized Save as label. Independent review also rejected a Main Page expression for Main, and corrected/rechecked finger and complicated vowels from rendered primary-source pages. Pencil now uses the explicit pencil expression from Luo's sharpening example. Watercolor uses an authored soft-edge-brush description plus the explicit technical identifier: the actual tool applies a blur mask and variable strength, including full opacity at 100%, so water-colour or translucent-only descriptions would mislead.

Recovery warnings preserve possible damaged/unreadable contents, the **ZIP and readable canvas.png** condition, optional/unverified settings and floating selection, and retention even when the exported copy cannot open. The existing ZIP-labelled recovery action identifies its export format, not verified content. Raw copy export does not inspect or repair those contents. Legacy unconditional resource identities are distinguished from the active unverified warnings.

RAM estimates distinguish resident canvas/copied selection, decoding and edit buffers from device file storage. Smallest-output failures, source preservation, unchanged originals and no automatic resizing remain explicit. Save, Save as, Export and sharing retain their different effects. Physical left/right, clockwise rotation, selected versus full canvas, font size/family and first-frame versus separate PNG default image remain distinct. Technical descriptions such as four 90-degree corners, RGB complement and integer examples preserve meaning without claiming standardized terminology.
