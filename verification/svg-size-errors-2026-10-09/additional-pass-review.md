## Remaining exact gap

No inspected default/source entry supplies the actual declaration-of-usable-original-size or canvas-derived-size-substitution proposition. Invalid PDF dimensions describe a different condition. Destination replacement errors state inability to replace an existing file, not that no fallback size was chosen. Those clauses cannot be repurposed unchanged without losing the new source meanings.

The additional source searches did find “invalid/too-large PDF page dimensions,” “normalized dimensions outside Android’s range,” “completed image could not replace its destination,” and no-resize/unchanged-size clauses. None establishes the missing SVG declaration or canvas-derived substitution predicate. Existing Hakka provenance verifies unrelated contextual readings and orthographic conventions; it does not supply those missing predicates.

All 11 locale-specific uncertainties in the original JSON remain applicable. The new evidence narrows the no-resize part of that uncertainty; it does not justify inventing declaration/substitution grammar or script mappings.
