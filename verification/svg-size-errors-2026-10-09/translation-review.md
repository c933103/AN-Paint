# SVG original-size error translation proposals

Source: [5bf82b67199aaecbd341a8b150a887f8d60b5567](https://github.com/c933103/AN-Paint/blob/5bf82b67199aaecbd341a8b150a887f8d60b5567/Paintroid/src/main/java/org/catrobat/paintroid/classic/SvgOriginalSize.kt). The requested source snapshot is unchanged by this work.

Coverage: 48 complete proposed pairs across 59 tags; 11 pairs deliberately withheld with exact uncertainties. This is 96 proposed string values and 22 null values, not 118 accepted translations.

The supplied snapshot and local source were inspected. The source checks finite positive dimensions, then ceiling-to-integer dimensions against Int.MAX_VALUE. The new size-limit wording must not be confused with the independent SVG 32 MiB file-size message or the editing-memory budget. No production resources were edited.

## Proposal status and limits

- All non-English strings are source/catalogue-assisted proposals; no independent native-speaker review, user acceptance, or full-catalogue completion is claimed.
- Existing catalogues are terminology evidence, not authority. The repository’s withdrawn-status notice remains in effect.
- All proposed pairs retain both source sentences, SVG/Android identities, and unqualified “no resizing.” No automatic-only or shrinking-only qualifier was copied from the old memory warning.
- Null values are unresolved work. Do not insert the English source or another language as if it were an accepted translation.
- The machine checks establish only exact scope, string presence, technical tokens, placeholder absence and XML-safe text; no Android build, visual check, or linguistic certification was performed.
