## What the fuller catalogue adds

- `formats22_ico_dimensions_error` has `hergen de araha kemun`: a dimension written in file metadata.
- Assembly-memory and smaller-output clauses already use `da kemun` for original dimensions; the new wording need not inherit the questionable adverbial `daci` construction.
- Normalization supplies `i songkoi` with a numerical dimensional basis; other setup/error clauses supply `toktobuha kemun` and the determine verb.
- The animation poster does not itself attest a substitute postposition. The new `da kemun i funde` is supported separately, with its genitive argument explicitly checked.

## Rejected shortcuts

- The source-condition clause uses toktobuhakū (not fixed/specified) but the new unavailable message instead uses the more transparent existing in-file araha kemun phrase.
- Animation poster text expresses not importing one set and importing another. It does not supply a standalone equivalent of instead of.
- Avoid object-ambiguous orolome; use the independently attested genitive + funde with an explicit replacement target.
- Avoid perfective arafi/baitalafi sequences that could assert the substitute had already been used.
- Avoid replacing the scoped bitmap identity with a generic large-image memory failure.
- Use the already-existing da kemun phrase instead of assuming daci is an adjective.
