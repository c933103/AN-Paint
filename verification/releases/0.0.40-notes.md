# AN Paint 0.0.40

Package `paint.anpaint.android`, version code 97.

## Changes since 0.0.39

### Expanded Swedish support

- Add 350 Swedish entries covering active Help and assembly Help, crop messages, Exact position guidance, Commons diagnostics and image credits, page controls, colour controls and drawing hints. Correct eight existing messages. Swedish resource coverage increases from 365 to 715 of 717 current entries, substantially reducing English fallback.
- The corrected Curve hint has independent model-based review of its complete wording and current control behavior. This closes that entry's missing independent-review qualification, not the other language holds or a new review of the previously accepted pairs.

### Vertical messages and tooltips

- Add vertical foreground messages on Android 11 and later and vertical tooltips on Android 8 and later for Mongolian, Manchu, Classical Chinese and the vertical test profiles.
- Keep long messages reachable in scrollable cards with a fixed dismiss control. Short fitting messages remain touch-transparent. Tooltips stay within their Activity or dialog and preserve existing Help actions and editor focus. In windows too small for a usable card, retained feedback waits for sufficient space.

### Corrected instructions and Afrikaans wording

- Clarify English assembly Help: snapping rejects overlap, while Exact position allows it and leaves other images in place. Explain zero-based whole-pixel coordinates and avoid promising that every removal moves other images to fill a gap. Exact position itself was already available in 0.0.39.
- Correct five Afrikaans priority messages: the language picker's English-fallback explanation, incomplete encoding, saved-image sharing, lossless compression and pixel-count wording. This is a bounded wording correction, not whole-language acceptance.

### Testing and maintenance

- Improve position-dialog test swipe targeting, runtime fixtures and bounded CI cancellation budgets without relaxing native-input, text, accessibility or failure checks. These are test changes, not a new production IME fix.
- Preserve the corrected 0.0.39 release description and guarded notes-maintenance tooling. The previous release's APK is unchanged.

### Known limits

Swedish is not completely localized or independently approved as a whole language. The existing Main-label hold remains; the ambiguous third palette argument and dormant full manual remain absent. Native-speaker review, installed Swedish layout and TalkBack acceptance are not established.

Nine Afrikaans terminology/context holds remain: three attribution-credit messages, GIF dithering, sampled decoding, busy/draft wording, the third palette argument, Main and the hexadecimal label. Installed Afrikaans layout, native-speaker and TalkBack acceptance are not established.

Other-language assembly Help still needs its own complete source-binding checks. Existing glyph/shaping and cross-language layout/input/accessibility work remains open, including the unsupported-ZWJ ink-bounds counterexample. Emulator and host checks do not establish universal physical-device, TalkBack or Android 5/7 compatibility. The [language tracker](https://github.com/c933103/AN-Paint/pull/56) retains the wider work. The newer unpublished Czech batch is not included.

### Verification and provenance

The exact release-source [natural build](https://github.com/c933103/AN-Paint/actions/runs/39452992495) passed all nine jobs: 1,250 JVM tests, release lint with zero issues, nine resource-generation probes, and the selected SDK-aware device inventories on API 30 (103 tests) and API 35 (119 tests). The recorded SDK suppressions and exclusions remain explicit; these counts are not whole-app or all-device certification.

The APK retains the existing upgrade-signing identity. Matching corresponding source is supplied separately and embedded in the APK. Verification details and checksums accompany the release.
