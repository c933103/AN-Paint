# AN Paint 0.0.38

Release candidate: package `paint.anpaint.android`, version code 95.

## Changes since 0.0.32

- Restored labelled cursor Start/Stop controls and the 120 dp magnifier, with
  image-pixel lens scaling and preserved cursor geometry.
- Added and corrected scoped language catalogues, script-aware UI typography,
  native tooltips, language-picker presentation and localized numeric entry.
- Improved image-credit session handling and autosave recovery, including
  interrupted saves and accepted-credit recovery across a process restart.
- Added Commons blank-map/image imports and associated attribution handling,
  with scoped Help and import-change translations.
- Improved gallery controls at large text sizes, native search and vertical
  descriptions, plus Back navigation for the effective RTL app language.
- Corrected protected-draft warning routes and added vertical-notice resize and
  accessibility characterization with compiled resources.

This candidate includes accepted `develop` changes through
`7e8a0d2377693a35cd9392f2082ef88548a6f67f`. Unmerged PR #34 is excluded.
Localization remains subject to the scoped recheck register; automated checks
do not certify translation accuracy or complete every locale.
