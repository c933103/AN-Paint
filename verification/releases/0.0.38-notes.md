# AN Paint 0.0.38

Package `paint.anpaint.android`, version code 95.

## Changes since 0.0.32

- Restored labelled cursor Start/Stop controls and the 120 dp magnifier, with
  image-pixel lens scaling and preserved cursor geometry. Tapping the cursor
  toggles drawing without painting a dot; moving elsewhere positions it.
- Improved reduced-scale canvas previews while keeping magnified pixels crisp
  and preserving the original image pixels. Improved image insertion and undo
  history across editing sessions.
- Added and corrected scoped language catalogues, script-aware UI typography,
  native tooltips, language-picker presentation and localized numeric entry.
- Improved image-credit session handling and autosave recovery, including
  interrupted saves and accepted-credit recovery across a process restart.
- Added Commons blank-map/image imports and attribution handling, with scoped
  Help, import-change notes, and localized Copy-credit failure messages.
- Corrected mixed-script Korean resource selection across picker changes and
  rotation, while retaining its public language identity. Includes the accepted
  PR #34 integration and exact-script resource-generation checks.
- Improved gallery controls at large text sizes, native search and vertical
  descriptions, plus Back navigation for the effective RTL app language.
- Corrected protected-draft warning routes, native slider gestures inside
  scrolling forms, vertical-text redraw after content changes, and the neutral
  warning title for uncertain animation detection.
- Corrected the scoped TIFF descriptions to qualify possible file-size savings
  from compression, including the separate Cyrillic Mongolian correction.
  Compression still preserves pixels; file-size reduction is not guaranteed.

This release includes the accepted source at `2c1bd8622eb6c57444eee8f816194b309fff136e`, including PR #43.
The 475-row localization recheck register remains the acceptance record;
unresolved rows are still open. These scoped changes and automated checks do
not certify translation accuracy or complete every language. No physical-device
verification is claimed.
