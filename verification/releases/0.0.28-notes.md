AN Paint 0.0.28 reviews the translation-catalogue pull request and fixes the traditional Mongolian language option.

- The Mongolian option uses its native name and `[mn-Mong]`, with two joined words in adjacent vertical columns and no English gloss. Checked in portrait, landscape and enlarged text.
- Coverage now accounts for all offered language choices. Starter Save translations also appear in the unsaved-changes prompt.
- Corrected unsupported starter vocabulary and contributor instructions. Ainu and the Tai collection retain English fallback; starter translations remain partial and need native-speaker review.
- The translation consolidation preserves all 4,867 pre-existing strings. Existing drawing, import/export and earlier colour/zoom fixes remain included.
- The release build fixes the native compiler configuration, including 32-bit HEIF file offsets and adds full release-variant Android 30/35 verification.
