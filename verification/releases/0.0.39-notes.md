# AN Paint 0.0.39

Package `paint.anpaint.android`, version code 96.

## Recent changes

- Add 148 independently reviewed Swedish priority messages.
- Correct 10 Korean and 18 Taiwan Chinese priority messages, including operation guidance, terminology and warnings.
- Correct six previously reviewed Malay, Indonesian, Japanese, Hong Kong Chinese and French messages. Assembly progress now describes processed inputs, including inputs skipped after size rounding.
- Show the appropriate wait message when retained image-credit attachment is blocked by another operation or by autosaving.
- Derive Wikimedia Commons image and metadata request identities from the installed application version.

This release includes the merged source through `e50de18df623ca03c9ddf3595f5612b36072510d`. [All source changes since 0.0.38](https://github.com/c933103/AN-Paint/compare/v0.0.38...e50de18df623ca03c9ddf3595f5612b36072510d).

## Verification and limits

The published verification asset identifies the exact release-build run, APK and corresponding-source hashes, upgrade certificate, and selected Android test results. The APK uses the existing upgrade identity. The source ZIP is also embedded in the APK.

Language review remains partial and bounded to the recorded entries. Untranslated text can fall back to English; unresolved linguistic, layout and accessibility items remain in the [language tracker](https://github.com/c933103/AN-Paint/pull/56). This release does not certify every language, every physical device or Android 5/7 compatibility.
