# AN Paint 0.0.39

Package `paint.anpaint.android`, version code 96.

## Changes since 0.0.38

### Image assembly enhancement

- Add Exact position for a selected image: enter zero-based whole-pixel X/Y coordinates, deliberately overlap images, and keep other images in place. Positions are saved with the assembly and support undo/redo. Later imports draw over earlier ones; edge snapping still rejects overlapping drops.

### Interface and behavior fixes

- Improve Advanced Colour in short landscape layouts, with separately scrollable editing and saved-colour/preview areas, wrapping captions and retained state when the layout changes.
- Make long About headings and notice headings/actions scrollable rather than truncated, and retain notice reading position when the window changes.
- Keep UI fonts and horizontal/vertical direction tied to the selected language through configuration changes. Correct Mongolian suffix shaping and nonbreaking text handling.
- Use the selected language's number formatting in image dimensions, memory budgets, selection/zoom summaries and recent-colour descriptions. Correct singular counts in English/French and plural routing for the emoji-English test locale.
- Preserve crisp source pixels in original-size assembly previews and exports, and align preview selection and stacking with export order.
- Correct misleading New-image, sampled-resize/transparency, crop-movement, PDF-failure and unsupported-colour-profile guidance.
- Distinguish unavailable credit text, missing external-link handlers, restricted redirects, unavailable native image components and file-picker failures. Show the appropriate wait message when credit attachment is blocked by autosaving or another operation.
- Prevent leading glyphs being clipped in Android 15 gallery status messages, including when replacement text has the same height.
- Localize all 12 previously hard-coded application-authored Commons metadata/import failure reasons across the scoped catalogues. Derive Commons request identification from the installed app version.

### Languages and text

- Increase the language picker from 140 to 171 choices, including historical languages and named Nahuatl/Quechua varieties. Migrate the former Tagalog code to Filipino while retaining the saved selection. Many added choices still use English fallback.
- Add reviewed Polish/Czech priority text, expand Swedish priority coverage, and correct Korean, Taiwan Chinese and other scoped catalogues.
- Add localized Exact position controls and improve assembly/save/export Help, warnings and attribution wording across affected languages.
- Extend bundled Nôm glyph coverage for added text and correct bundled-font licence references.

### Known gaps

Language completion and review remain partial. A selectable language is not necessarily fully translated. Some assembly Help wording still needs alignment with Exact position and snapping. Cross-language layout, input and accessibility work remains unfinished, including vertical notifications/tooltips.

This release does not establish universal physical-device, TalkBack or Android 5/7 compatibility. The [language tracker](https://github.com/c933103/AN-Paint/pull/56) retains unresolved work.

### Downloads and provenance

The APK retains the existing upgrade-signing identity. Matching corresponding source is supplied separately and embedded in the APK; verification details and checksums are attached to the release.
