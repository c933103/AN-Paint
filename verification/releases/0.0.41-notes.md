# AN Paint 0.0.41

Package `paint.anpaint.android`, version code 98.

## Changes since 0.0.40

- Expand priority translations across the 171 language options and repair existing wording for saving, recovery, import, crop, assembly, colour controls and Help. All 94 P0 and 249 P1 resource identities are now directly present per option. This measures resource coverage, including aliases and technical notation, rather than complete native-language prose.
- Review the existing resource inventory in finite, recorded scopes and correct identified meanings, instructions and units. The final two wording checkpoints alone correct 107 existing values across 39 catalogues.
- Clarify recovery-copy notices: preservation and export do not verify that the contents are readable. Extract `canvas.png` only if the exported copy opens as a ZIP and contains a readable image; keep the copy even if it cannot be opened.
- Let long horizontal numeric-slider captions wrap while retaining the minimum touch target. Keep long Fit captions and status text reachable without resizing the canvas whenever the status changes. Improve access to enlarged colour-editor controls in wide landscape layouts.
- Preserve the selected app language across framework configuration resets while keeping WebView assets and resources together. Correct packaged resource routing for Valencian and Yiddish.
- Fall back to the complete English source when a translated formatted message has an invalid argument contract, instead of losing the warning or failing to format it. Preserve literal percentage wording and pasted Unicode minus signs for existing numeric validation.
- Localize malformed ICO/DIB image errors without relabelling unrelated storage or provider failures. Reduce repeated work when fitting long vertical captions while retaining complete control text and tooltips.

## Known limits

Priority coverage and recorded source/model review do not establish complete localization of every catalogue, native-speaker fluency, universal glyph/shaping or layout support, or installed accessibility acceptance. New or untranslated text can still appear in English. The application retains English fallback for missing or invalid resources; direct coverage does not remove that safety path.

The 45 dormant legacy manuals were read and dispositioned separately. Most retain stale-content or wording findings and are not approved for current or future use; Czech is the aligned-content exception. No production literal/alias route was found, but dynamic unreachability has not been established. Missing P2/P3 translations remain outside this completion claim.
