AN Paint 0.0.31 fixes cursor positioning and exposes image compression settings in Save as.

- Cursor drawing starts with positioning only. Use the visible Start drawing / Stop drawing control below the canvas to enable or pause ink. Short strokes and undo are preserved; opening cursor settings or reopening the app pauses ink.
- Cursor settings now sit under View and beside the drawing control. They include brush, size, round/square shape, magnifier zoom and marker visibility. The Paintroid marker remains visible at fitted zoom without changing brush size.
- Save as contains ordinary image formats. JPEG XL, WebP and AVIF offer lossless or lossy modes; JPEG, JPEG XL, WebP, HEIC and AVIF expose applicable numeric quality settings. TIFF retains Deflate compression and GIF retains dithering. Save remembers the successful destination and settings.
- Export as contains ICO, ASCII art and Base64 text. These exports preserve the editor's current Save destination and unsaved state.
- Selected GIMP editor vocabulary improves common terms across 81 language bases. Coverage remains partial. The original translator credits, source details and full GPL licence are accessible under File → About, licences & credits. Reviewed regional and action translations retain precedence.
- The main canvas and magnifier keep bitmap filtering off; drawing antialiasing remains off by default.

Package: `paint.anpaint.android`, version code 84. Universal, non-debuggable APK with the existing upgrade certificate, four ABIs and 16 KB alignment. Exact corresponding source is included in the APK and as a separate release asset.

Adds 20 GIMP language choices and explicit Tatar Cyrillic/Latin options. The Latin starter catalogue is transcribed from the Cyrillic source; legacy tt migrates to tt-Cyrl.

The combined third-party licence notice now matches the generated build copy. Build preparation rejects stale generated legal assets before packaging, keeping the bundled source tied to the recorded commit.

Verification: 80 local host checks; 261 release regression tests; zero app lint issues; 78 instrumentation tests on API 30 and 79 on API 35. All passed.
