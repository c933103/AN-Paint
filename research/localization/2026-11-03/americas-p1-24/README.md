# Americas localization: 24 P1 strings

This evidence-only record covers 24 original P1 gap fills: Chamorro 3, Cherokee 7, Eastern Huasteca Nahuatl 4, Central Huasteca Nahuatl 5, and Western Huasteca Nahuatl 5.

Application commit: [6da0cbf0e3b171b4d83adcf8a22988809def93d0](https://github.com/c933103/AN-Paint/commit/6da0cbf0e3b171b4d83adcf8a22988809def93d0). Application tree: `11d6839cae91cdcbb35f0be550cf3726ac596dcf`.

- `accepted-strings.json` preserves exact Android raw text, displayed text, attributes, placeholders, backtranslations, caller anchors and confidence limits.
- `source-review-evidence.json` preserves sanitized primary-source records and accepted-row subsets of independent reviews. Original SHA256 pins identify the immutable source receipts; sanitized derivative bytes have different hashes.

The research separately checked own-variety source forms, direct callers and resource identity. No claim of native idiom, glyph coverage, layout, accessibility or runtime certification is made.

Important limits: two Nahua prompts functionally say to select an image first rather than prescribe a physical tap; Cherokee editor show/hide entries are dormant semantic slots; numeric prompts distinguish fractional text sizes, percentage inputs, rounded output pixels and inclusive bounds. Chamorro diagnostics distinguish a blocked picker from missing single and multiple results.

Raw values are XML-parsed Android text. Escape XML once when emitting resources. Chamorro ASCII apostrophes carry one Android backslash; Navajo is not part of this batch.

Primary sources are linked in the evidence file. Whole research PDFs and unrelated data are not copied here. This commit changes evidence files only, not application resources.
