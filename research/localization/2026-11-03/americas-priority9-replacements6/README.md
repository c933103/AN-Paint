# Nine P1 labels and six menu-reference replacements

Application commit: [2300b05674441582628ff06cd11f190b540a363a](https://github.com/c933103/AN-Paint/commit/2300b05674441582628ff06cd11f190b540a363a). Tree: `32088c591daae84f010f021a8b1ca5da30972391`.

This record contains **9 new original-P1 strings**: three Chamorro viewport/preview controls, two Chicontepec app-language labels, and four Central/Western Nahuatl Load/Share labels. It separately preserves **6 existing-guidance replacements**, each changing one quoted Load image label and nothing else. The replacements earn zero new-gap credit. Exact old/new parsed Android values, attributes, occurrence counts and review pins are included.

The Fit labels change the viewport, not source pixels. Preview magnification is a relative lens multiplier. App-language labels do not change the device language. Central/Western Open commands are source-supported own-variety analogies, not directly published commands; Share names stored output and a user-operated chooser. The Load labels and matching guidance are a same-batch dependency.

These remain source/compositional translations without native, runtime, glyph or layout certification. Unknown PNG and unrelated held candidates are excluded.
