## Limits

All five target phrases are compositions. full-phrase-search.json documents no exact full target phrase in the four retained files, not a claim about all translations worldwide. Source translations themselves can be imperfect. Component evidence must not be promoted to direct phrase attestation.

Basic retains the everyday basic category sense. It is not labelled primary colours and no scientific-primary-colour interpretation is asserted. The add/edit/use objects remain actual colours, never palettes. Selected is a descriptive preview label; the other three are actions. Specific-colour case marking and action register require native review. The Selected noun phrase is composition from a relative form with accusative suffix removed.

Inherited Palette uncertainty and held Solid fill and Calligraphy remain outside scope. This dossier changes no accepted status and contains no production edits, build/test claims or remote publication.

## Clarified consumer roles

- ui_basic_colours: Labels the 48 built-in swatches, not scientific primary colours.
- ui_selected_colour23: Labels the current valid preview, which may be provisional until Use colour.
- ui_add_colour26: Outer action opens the custom-colour slot editor. A full palette asks which slot to replace; this label must not promise immediate allocation or saving.
- ui_edit_colour26: Opens the existing custom-colour slot editor. Its separate confirmation says Save; Edit is not itself that save action.
- ui_use_colour: Accepts the current foreground/background colour value. It does not save the image or recolour existing pixels.

These roles were supplied by the coordinating task after its consumer verification. The lexical author has not independently reverified those callers. Prior Edit background wording does not establish a blanket translation style mandate.
