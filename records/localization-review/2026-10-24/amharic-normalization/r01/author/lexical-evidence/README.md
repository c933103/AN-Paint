# Amharic assembly normalization lexical draft evidence

Six original drafts only: five offered for independent review; the plural restoration command remains on author idiom HOLD. None is implemented or independently accepted. No native-reader, rendering or runtime assurance is claimed.

The corpus contains complete immutable source snapshots with recomputed SHA-256 values, exact PO/XML records including genuine variants and rejected evidence, current canonical English records, bounded searches, and per-key rationale. Source URLs are pinned. A fresh web open of the pinned LO UI file failed with a cache miss; the task reuses existing complete hash-verified snapshots and does not call that a fresh retrieval or a denial.

`draft-candidates.json` is the review input. `sources.json` links snapshots to URLs/hashes. `exact-records.json` keeps raw records, line references and roles. `search-records.json` keeps the bounded PO query results; XML matching was limited to the paired keys cited in exact records. `validation.json` is structural evidence only.

Important distinctions:
- Same width/height chooses a shared dimension for all inputs, preserving each crop ratio, not uniform whole-image shape.
- Smallest/largest refer to current placed width/height and stage a target only. They are not area/file-size or immediate resize actions.
- Apply to all applies to every assembly input, including unplaced inputs.
- Restore original sizes acts immediately, removes normalization only, retains crops and may reflow attachment placement. No global Undo/file rollback/crop-reset promise is added. English explanatory help already qualifies this; no English defect is established.

Variants are deliberately preserved: AOSP Height ቁመት versus LO እርዝመት; same ተመሳሳይ versus equality construction እኩል ማድረጊያ; Smallest ትንሹ versus AOSP አነስተኛ; Apply imperative ተግብር versus noun-label መፈጸሚያ; Original Size ዋናው መጠን versus ዋነኛው መጠን. No variant is silently flattened or accepted by prior review of a component.

The restore draft is ዋናዎቹን መጠኖች መልስ, but the plural adjective/object idiom is not established by the corpus. It remains HOLD rather than forcing acceptance or silently narrowing the source to a different operation.
