The first two method/shape constructions are original proposals, not quotation or source-attested complete captions. Eyedropper's exact analogous source does not prove idiomatic quality. Bucket Fill omits the bucket metaphor and transfers a colour-filling label into a connected-region tool. Preserve the holds if independent review cannot establish contextual naturalness. No forced acceptance is warranted from lexical precedent alone.

Complete source snapshots include four pinned LibreOffice PO files, one pinned GIMP PO file and the institutional ICT glossary PDF on its documented third-party mirror. These are copied and rehashed snapshots, not claimed fresh downloads. The glossary's rendered pp104, 113 and 188 were visually inspected to verify the Amharic column and row alignment. Its complete PDF and all full-page images/text are LOCAL REVIEW ONLY and must not be uploaded with a public dossier. Only bounded terms, metadata, links and original rationale are intended for publication; see publication-limits.json.

exact-po-records.json preserves exact msgid/msgstr/context, raw blocks, flags and line locations. exact-glossary-records.json records precise source entries and page images. excluded-gimp-records.json prevents fuzzy misleading selection text or empty Bucket Fill / Color Picker strings from being mistaken for evidence. draft-candidates.json gives rationale, alternatives, confidence dimensions and review questions. sources.json and SHA256SUMS bind the files.

Source consumers were supplied in ../consumer-context.json. This lexical package does not independently certify those consumers, runtime rendering, larger composed accessibility/status/help strings, existing acceptance, or production coverage. Earlier 90 ready / 14 held labels are untouched.
