## string/ui_bucket_fill

English: Bucket fill

Proposed XML: `<string name="ui_bucket_fill">"ቀለም መሙያ"</string>`

FILL tool fills a connected region from the touched pixel with document foreground. Pointer-up delegates to onFill, activity runs document.fill via backgroundEdit; ScanlineFill walks horizontal runs and above/below neighbours, accepting colours within squared RGBA-distance threshold from original seed.

Qualification: Bucket is a painting-tool metaphor, not filling a physical container, whole-canvas clear, shape interior style, gradient or disconnected same-colour replacement. Tolerance zero requires exact pixel equality; positive threshold uses squared RGBA distance, not an ordinary percentage of image area. Bounds/same-colour early return and failure restoration are preserved; no guaranteed operation success. Choosing the tool is distinct from tapping to fill, though tool switch may commit prior work. No new tolerance/hint acceptance.

## string/ui_eyedropper

English: Eyedropper

Proposed XML: `<string name="ui_eyedropper">"ጠብታ መለኪያ"</string>`

PICKER tool reads the current bitmap pixel at in-bounds pointer-up coordinates and sets document.foreground. onPick adds recent colour, refreshes colours/status and schedules autosave.

Qualification: Single image-pixel colour sampling, not choosing an image/file, opening a general colour dialog, averaging a neighbourhood or automatically sampling background. No physical medical-dropper action. Sampling itself changes foreground property rather than painting pixels; switching away from a floating selection can commit that selection first. Larger help/status/selected-category phrases outside label review.
